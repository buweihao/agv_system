# AGV 调度系统地图配置规范

## 1. 核心模型关系

在 AGV 调度系统中，地图网络由节点（`MapNode`）和边（`MapEdge`）构成，其他所有与空间位置相关的实体都必须依赖于这些基础节点。具体关联关系如下：

- **MapNode (地图节点)**：代表地图中的一个物理坐标点或逻辑站点。拥有唯一的 `NodeId`。
- **MapEdge (地图路径)**：代表连接两个 MapNode 的有向边。必须具有有效的 `FromNodeId` 和 `ToNodeId`。
- **ChargeStation (充电桩)**：`NodeId` 字段必须引用一个已存在的 `MapNode`，并且该节点的 `NodeType` 应配置为 `Charge`。
- **Vehicle (车辆)**：
  - `HomeNodeId` (待机点)：必须引用一个已存在的 `MapNode`。
  - `ChargeNodeId` (默认充电点)：必须引用一个已存在的 `MapNode`，且通常应为 `NodeType=Charge`。
- **TaskOrder (任务单)**：
  - `SourceNodeId` (起始点)：必须引用一个已存在的 `MapNode`。
  - `TargetNodeId` (目标点)：必须引用一个已存在的 `MapNode`。
- **MapLocationAlias (地图别名)**：用于将逻辑名称（如车位名称、产线对接点名称）映射到具体的 `MapNode`，方便上层业务使用别名下发任务。

## 2. 命名规范

- **节点命名 (NodeId)**：推荐使用全大写字母加数字，如 `A1`、`B2`、`CHG-01`、`HOME-01`。
- **路径命名 (EdgeId)**：推荐使用 `E-起始点-终点` 的格式，如 `E-A1-A2`。
- **区域命名 (ZoneId)**：代表物理逻辑区域，如 `ZoneA`、`Warehouse`。用于对节点进行分组。

## 3. 坐标系与单位

- 地图使用的 `X` 和 `Y` 坐标必须统一单位（默认推荐以**米 (m)**为单位）。
- 计算路径距离时，系统直接根据节点坐标计算欧式距离，若需要精准配置实际运行距离，可使用边或节点扩展属性覆盖。

## 4. 品牌与能力限制规则

为了支持多品牌异构 AGV 混合调度，系统在节点和边上支持以下限制属性：
- **AllowedBrands (允许品牌)**：用逗号分隔的品牌字符串（如 `BrandA,BrandB`）。如果为空，则允许所有品牌通过。如果设置了特定品牌，则只有匹配的车辆才能通过或分配到该节点/边。
- **RequiredCapabilities (能力要求)**：一个位图枚举。车辆在被派发至该节点，或经过该边时，必须具备这里声明的所有能力，否则会被底层路径规划和调度系统拒绝。
- **IsEnabled (启用状态)**：若节点或边设置为 Disabled（`IsEnabled = 0` 或 `false`），则路径规划算法将完全无视其存在，且调度引擎也会将其视为物理阻断区域。
